## Selected engineering work

> Most of my recent professional projects are private client systems, so the cases below are intentionally anonymized.

### Enterprise procurement ecosystem

Built and evolved an integrated procurement module for a large enterprise platform used by **100+ users** and handling approximately **2,000–3,000 processes per month**.

The solution centralized workflows previously spread across a legacy system, spreadsheets and WhatsApp, connecting supplier management, purchasing, warehouse operations, fiscal processes, finance/accounts payable and a freight workflow that I also developed. The redesigned process reduced cycles that could take **one week or more to as little as two days**, depending on the purchasing flow.

**Stack:** Angular · NestJS · Node.js · MySQL · REST APIs

### AI-powered enterprise reporting platform

Worked on the architecture and backend of a platform that collects external business data, normalizes results and generates automated reports enriched with generative AI.

Implemented and evolved patterns involving **provider abstraction, OpenAI/Gemini integrations, Structured Outputs, JSON Schema validation, RBAC, auditability, asynchronous processing with BullMQ/Redis, dedicated workers, health checks and operational observability**.

**Stack:** TypeScript · NestJS · Node.js · PostgreSQL · Redis · BullMQ · OpenAI · Gemini · Docker

### Automated data collection & analysis pipeline

Built and evolved automated data workflows focused on collection, processing and analysis across digital sources, with emphasis on reliability and traceability.

The architecture includes **idempotency, deduplication, auditing, canonical identifiers, standardized contracts between pipeline stages, automated testing and CI validation**.

**Stack:** Python · PostgreSQL · GitHub Actions · Automation · Data Processing

### Maintenance management platform

Designed and developed an end-to-end platform for internal and external maintenance operations, including work orders, configurable workflows, approvals, equipment, schedules, checklists, attachments, history, costs and operational tracking.

I have been responsible for the solution from product understanding and UX decisions through architecture, front-end, backend, database design and deployment support.

**Stack:** React · Next.js · NestJS · Node.js · PostgreSQL · Tailwind CSS · shadcn/ui

## How I approach engineering

I value software that is not only functional, but also **observable, testable, secure and maintainable**.

My day-to-day work often involves:

- translating ambiguous business needs into technical flows and deliverable features;
- defining or contributing to architecture, API contracts and engineering standards;
- reviewing code and discussing implementation choices with other developers;
- investigating production issues and identifying root causes;
- designing integrations between modules and external services;
- building automated tests and CI/CD quality gates;
- planning releases, migrations and post-deployment validation;
- continuously improving systems based on real production usage.
